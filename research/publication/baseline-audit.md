## Required research comparators

The existing v0.1 MLTools checker is a strong independent **stateful** baseline. It already checks origin anchors, queues, reset and named commands. It must receive the same authority, artifacts and observations as the proposed compiler where their supported semantics overlap. Reusing the compiler evaluator and renaming its output would not produce an independent implementation.

Pointwise affine reference replay is another useful comparator, but not the strongest possible manual method. Missing offsets can make pointwise replay abstain while paired differences still expose a known coefficient. A manually authored paired stateful oracle can exploit exactly the same cancellation. Include it, with equal query access, and report parity if it matches the compiler. A benefit of systematic generation or reduced witnesses must be measured separately from detection.

The development implementation now includes an independent strong pointwise/all-pairs/midpoint oracle on the same supplied design (`docs/research-oracles.md`). `development/oracles-002/` records matching compiled/strong-oracle results from genuine saved captures and a clean wheel environment. Propagated basis budgets prevent contrast cancellation from imposing an artificially stricter tolerance. Finite-query agreement cannot clear missing full-design rank; stateless agreement is limited to saved equal-state queries. This is not an optimized manual query generator, a v0.1 checker comparison, or a final matched-evidence experiment. No speed claim should use the all-pairs implementation as a stand-in for an optimized basis oracle.

Static declarations, round trips, stateless replay and random/manual probe selection need explicit input contracts. Inverse round trips can preserve a shared incorrect mapping; still run real native encode/decode paths on their supported domains. A stateless ablation removes temporal information without deleting unrelated reference or provenance evidence. Random/manual probes require newly executed queries at matched budgets; existing canonical captures cannot be reinterpreted as unobserved random interventions.

[Tai's ExecSpec paper](https://arxiv.org/html/2606.03724v1) directly covers quantile-normalizer metadata substitution. Its certificate uses calibration actions, decoded displacement, tails, mask differences and gripper attribution. A reimplementation must preserve normalization domain, mask and clipping conventions, disclose deviations and avoid inventing a universal safety threshold. No author implementation link was identified in the inspected HTML and bounded search; this is not proof that no implementation exists. The paper's reported simulator outcomes have not been reproduced here.

## Additional close tools discovered

The pinned [robotruth source](https://github.com/mulkakhileshmj/robotruth/tree/8eb1704cf446239e3f03687c2ebd707cbab68e98/src/robotruth/contract) implements manifest extraction and severity-based comparison of normalization, action mode, chunk length, executed steps, rate, cameras and embodiment. Unknown fatal fields block certification; units and absent camera calibration hashes can be warnings. Its reported PASS/FAIL must not be described as identical to MLTools' tri-state semantics. Extraction reads artifacts without framework execution and uses some family-specific heuristics; truthful overlays and exact artifact freezing are required. The inspected manifest/checker has no explicit origin-anchor/reset/refill contract. Its [policyci ACT adapter](https://github.com/mulkakhileshmj/robotruth/blob/8eb1704cf446239e3f03687c2ebd707cbab68e98/policyci/src/policyci/policies/act_aloha.py), however, really loads ACT, resets it and selects actions. Framework execution alone therefore does not distinguish MLTools from the repository as a whole.

The pinned [ActionABI source](https://github.com/Archerkattri/actionabi/tree/5ad1d45a082860f5f16bb43f3c6bbb0758ec6c11/src) implements held-out finite-grammar scoring, retained equivalence sets with field-level identified/ambiguous/unsupported status, converter refusal, bounded signed axis pulses, and exact/greedy selection of probes separating hypothesis pairs. Partial-evidence abstention and distinguishing probes are prior implemented machinery. The selector consumes caller-supplied predicted observations and safety flags; generating those predictions has a cost and does not itself establish safe device execution. The inspected CPU scorer assumes equal state/action dimensions, at least two episodes and a specified transition-response model. Current processor traces do not automatically satisfy those assumptions. Its grammar includes lag, but no explicit chunk-origin/cache/reset rule.

A fair ActionABI comparison must exercise the equivalence/refusal and probe-selection **library APIs** or complete experiment path. The pinned `infer` CLI only scores supplied hypotheses and would underrepresent the method. Freeze hypotheses/calibration and charge for candidate predictions; unsupported temporal cases are N/A, not misses. A temporal extension must be labeled separately from stock code. A fair robotruth comparison includes extraction plus checking with the same authoritative overlays; withheld certification is not a false alarm or successful fault localization.

One reused subagent performed this bounded source review; its inspected blobs are recorded in `competitor-sources.json` and matched to the pinned Git trees. Neither tool was installed or executed, and README performance numbers remain unverified publisher claims.

The narrower open question remains whether independently grounded, executed temporal boundary contracts provide a useful cross-framework workflow, corpus or diagnostic advantage over these alternatives. It is an empirical question, not a novelty conclusion. If the strongest manual/tool workflows match the proposed method, the paper must report that result and position any contribution accordingly.
