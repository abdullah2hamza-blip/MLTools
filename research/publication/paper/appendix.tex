\section{Interventions and query construction}\label{app:recipes}
The action dimension is six for ACT and SmolVLA and seven for PI05, including its OpenPI transport. Native action inputs lie in $[-0.8,0.8]^n$; the query design uses normalized coordinates $x=z/0.8$. Thus the canonical center and signed axes use 13 queries for a six-dimensional cell and 15 for a seven-dimensional cell. Each of the sixteen actual conditions is queried under eight designs: canonical, manual-axis, and random-axis/random-dense at seeds 7, 23 and 101. Summing these equal-budget designs yields the 1,792 primary calls. Manual-axis independently constructs the signed axes. Random-axis shuffles the axes and draws each amplitude uniformly from $[0.25,1]$; random-dense draws each direction component uniformly from $[-1,1]$. Both random designs include the center and each direction's negative. Their rank and finite-precision observability are checked on the actual executed coordinates.

Interventions select the first coordinate with positive source width, which is zero-based coordinate 0 in all selected groups. Let $w$ be its source standard deviation for MEAN\_STD, or $q_{99}-q_{01}$ for quantiles, and set $\Delta=\max(1,w/2)$. The offset condition adds $\Delta$ to the mean, or to both quantile endpoints. The slope condition doubles the standard deviation, or doubles the quantile width about its original midpoint. The composition applies that width change and then the offset. The shifts are approximately 2.109494, 9.784955 and 1.0 in ACT, SmolVLA and PI raw numerical coordinates, respectively; they have no asserted common physical units. In OpenPI the fixed $10^{-6}$ quantile allowance remains unchanged, so doubling the source width does not exactly double the effective decoder coefficient. These large declared changes test evidence distinctions, not sensitivity to subtle naturally occurring drift.

Injected derivative statistics are serialized as F64 with prepared configurations; numerical controls retain pristine source statistics bytes and F32 dtypes. Native numerical execution casts both to F64. The separate development-only unchanged-value serialization control isolates artifact-identity changes from numerical changes; it is not a selected condition. Exact values, file hashes and seeded queries are retained in the prepared plan and requests.

\section{Numerical profiles and reference assumptions}
For a normalized scalar $z$, LeRobot MEAN\_STD decodes $z\sigma+\mu$; its forward map divides by $\sigma+10^{-8}$. LeRobot QUANTILES decodes
\[
 \tfrac{1}{2}(z+1)d+q_{01},\qquad
 d=\begin{cases}q_{99}-q_{01}&q_{99}\ne q_{01},\\10^{-8}&q_{99}=q_{01}.\end{cases}
\]
OpenPI quantiles instead use $d=q_{99}-q_{01}+10^{-6}$ on every selected coordinate. The reference preserves the reviewed operation order, and neither selected quantile profile clips actions. A width or epsilon difference must not be hidden by relabeling profiles. Safetensors source arrays can be F32 or F64; the selected native numerical execution is explicitly float64. Policy Space later converts raw-vector wire arrays to float32, with separate recorded conversion error.

The independent parser never learns its reference coefficients from deployment responses. For a partial reference, unknown offsets/coefficients stay absent. The compiler's fragment-verification flag is a producer declaration backed by reviewed source, not a proof inferred from sampled closure. The observed output ULP floor diagnoses quantization; it does not bound every upstream arithmetic operation. The geometry harness's conditional component intervals additionally depend on its explicit measurement allowance. These assumptions delimit the full-affine status reported alongside finite-query outcomes.

The finite drift certificate baseline implements \citet{tai2026execspec}'s paper-equation quantile map on its stated coordinate domain. OpenPI and LeRobot variants are separately named extensions. It retains individual decoded values, displacement magnitudes and descriptive summaries. Raw coordinate labels, missing common metric units and unavailable demonstration calibration prevent safety or task interpretation. No threshold is chosen from selected outcomes.
