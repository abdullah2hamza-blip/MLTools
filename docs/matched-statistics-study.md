# Shared artifacts for numerical and identity workflows

`scripts/study_assets.py` compiles exact intended/deployment folders from pinned, permitted small metadata. A numeric control retains the original publisher configuration and statistics bytes. Explicit offset/slope/composed interventions rewrite the postprocessor action statistics as F64 arrays, rebuild valid Safetensors offsets/headers and retain every other tensor value. The original processor-style filenames, preprocessing statistics and source configuration remain intact. `runtime_profile.json` separately declares the current CPU/binary64 research operator profile; the publisher's training/inference runtime is not inferred.

The independently decoded reference uses the same bounded source-byte snapshot whose digest was checked. Both native workflows receive these exact leaf folders. The decoder genuinely loads each deployed Safetensors file, checks its values/dtypes against the separately decoded specification, then uses the native normalization operator. Robotruth uses its stock `extract_spec` and `check_contract`, with empty overlays, `allow_unknown=False` and no ignored fields. Missing weights, units or gripper evidence are never manufactured to obtain certification.

The last control is development-only, outside the selected main 24-condition design. The actual native decoder sees unchanged numerical values in that control, despite changed bytes. This demonstrates the different contract scopes: a strict identity difference is valid evidence for an identity requirement, and does not alone prove numerical inequivalence. It is not automatically a semantic false alarm. All public-checkpoint physical authority remains UNKNOWN, and no learned policy or task performance was evaluated.

The stock extractor hashes the union of referenced pre/postprocessor statistics files and assigns the same digest to action and observation normalization. A postprocessor action mutation therefore produces two native findings, which are both retained but counted as one underlying artifact difference. It does not establish changed observation numerics. Full native FAIL is also retained: missing fatal certification evidence is separate from known statistics inequality and is not a detected semantic fault or false alarm. Extracted action/embodiment conventions can be heuristics and are not physical authority for this study.
