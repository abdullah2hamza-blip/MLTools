# Third-party provenance

- Optional framework: [Hugging Face LeRobot](https://github.com/huggingface/lerobot/tree/5517a326eeb9b457cfe07d59b9bfdf291799c8d9), Apache License 2.0. Copyright headers remain in its installed distribution. MLTools imports that package; it does not vendor or relicense its source. The pinned commit, lockfile and captured Git blob identities identify the exercised implementation.
- SO-101 reference names/units: [`so_follower.py`](https://github.com/huggingface/lerobot/blob/5517a326eeb9b457cfe07d59b9bfdf291799c8d9/src/lerobot/robots/so_follower/so_follower.py) and [`config_so_follower.py`](https://github.com/huggingface/lerobot/blob/5517a326eeb9b457cfe07d59b9bfdf291799c8d9/src/lerobot/robots/so_follower/config_so_follower.py). Body joints use degrees when `use_degrees=True`; the gripper uses range 0–100. Physical calibration and hardware identity are not inferred.
- Public calibration fixture content: authored for this repository, including camera sentinels, state/action values, statistics and software configuration. No customer data, checkpoint weights, dataset recordings or credentials are included.
- Published checkpoint metadata: [yutofujita/smolvla-so101-move-cube, revision 0220b37dbcf1e0b2f6f5e21c64c75bf16fac6b69](https://huggingface.co/yutofujita/smolvla-so101-move-cube/tree/0220b37dbcf1e0b2f6f5e21c64c75bf16fac6b69), licensed Apache-2.0 according to its pinned model card. Pristine JSON and small normalization Safetensors files are attributed in the source manifest; derived files and deliberate wrong-statistics fixture are labeled separately. A copy of the Apache 2.0 license is included in that example directory. Weights and dataset recordings are excluded.
- Torch and other transitive packages retain their respective licenses and installed notices. `uv.lock` records resolved versions, dependency sources and available distribution hashes; it does not authenticate physical metadata or execute model code.
- Research source links and limited baseline evidence remain under `research/`. They must not be represented as framework execution benchmarks or endorsements of this tool.

Live verification canonicalizes LeRobot source line endings to LF before calculating Git blob SHA-1, matching Git's source representation across Windows checkouts. SHA-256 is used for local evidence artifacts. Neither digest mechanism proves source authorship, absence of malicious code, or authenticity of a recorded trace.
